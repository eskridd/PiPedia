# Contribution guidelines

Welcome aboard. PiPedia works because people write things worth reading and keep them honest. This page covers the ground rules, including how AI tools fit in.

## The short version

- Write clearly and get the facts right
- One topic per article, reasonable length, link generously with `[[wiki links]]`
- Anything misleading gets fixed or removed, same as anywhere else on this wiki

## Our stance on AI

You are welcome to use AI tools here, within limits:

**Allowed**

- Research help: finding leads, background reading, explaining a topic before you write
- Extending an existing draft: suggestions, rewording, structure ideas, as long as you review and take responsibility for every sentence that ships

**Not allowed**

- Pasting a whole AI-generated article and calling it done
- Keeping AI-written passages that contain false claims, invented numbers, fake quotes, or dead-wrong explanations

If your contribution turns out to be AI slop or carries AI misinformation, it will be deleted. Repeat it and you will be blocked. There is no appeal process for low effort.

## Why we care

An encyclopedia has exactly one product: information people can trust. A confident paragraph of nonsense costs every future reader more than it ever helped the author. Human curiosity, checked by human judgment, is the whole point of this place.

## Practical advice if you use AI anyway

- Verify every factual claim against a real source you have actually opened
- Run any code or command yourself before submitting it
- Read your draft out loud; if it sounds like a brochure, rewrite it like a person
- Cite primary sources where it matters (papers, docs, official stats)

## Everything else

Formatting help lives in the wiki's How-to-Contribute article. File names go Title-Case-With-Hyphens, big topics split into smaller pages, and the Sandbox exists so you can experiment safely. Thanks for contributing.
