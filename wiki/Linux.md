# Linux

**Linux** is a free, open-source operating system kernel created in 1991 by Linus Torvalds, then a 21-year-old student in Helsinki. Paired with GNU userland tools, it grew into the operating system family that now runs most of the internet, all of the world's top supercomputers, every Android phone, and a very vocal share of laptops.

## From hobby project to everywhere

Torvalds announced his "hobby" operating system on Usenet with characteristic understatement, saying it would not be big and professional like GNU. Thirty-plus years later, Linux powers:

- over 90% of the public cloud workload
- 100% of the TOP500 supercomputers
- Android, the world's most used OS by device count
- routers, TVs, cars, Mars helicopters, and in-flight entertainment systems

## Distributions

The kernel alone is not an operating system, so communities and companies bundle it with tools, package managers, and desktops into **distributions**. Debian, Fedora, Arch, openSUSE, and their many children (Ubuntu, Mint, Rocky) take wildly different approaches to the same core. The right distro is the one whose trade-offs match yours.

## A taste of the command line

```bash
ls -la
cat /etc/os-release
sudo dnf install htop || sudo apt install htop
htop
```

Four lines and you already know your kernel's OS family, installed a process monitor, and watched every program on the machine fight for CPU time in real time.
