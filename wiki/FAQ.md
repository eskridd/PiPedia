# FAQ

Quick answers to the questions people actually ask about reading, using, and improving PiPedia.

### Who can edit?

Anyone with a GitHub account. You do not need permission, an invitation, or write access to the repository. [[How-to-Contribute]] walks through every path into the wiki.

### Do I need to learn git?

No. Two of the three ways to contribute never touch a command line: open an issue with the New article template and a bot publishes your page, or click Edit on any article and GitHub guides you through proposing changes. Git is optional here, not required.

### Is this really free?

Yes. Reading and writing here cost nothing, there are no ads, and no one watches what you browse. The code and content are MIT licensed as well.

### Why is my brand new article not showing up yet?

The list of articles lives in a small index file that a robot rebuilds after every change, which usually takes a minute or two. If nothing appears after ten minutes, check the repository's Actions tab for a failed run, then mention it in an issue so someone can look.

### Can I add images?

Yes. Put image files in the wiki folder and reference them with ordinary Markdown relative to your article, like `![a red fox](Red-Fox-photo.jpg)`. Hotlinking pictures from other websites will not work because the site blocks outside images on purpose, so commit the file alongside your article instead. Keep files reasonably small, and only upload images you have the right to share.

### Does search send my typing anywhere?

No. Pressing <kbd>/</kbd> opens the search box, and all of it happens in your browser: it downloads the article list once, searches locally, and tells nobody anything.

### I spotted an error. What should I do?

If you can fix it, please just fix it. Edits are reviewed quickly and mistakes happen to everyone. If you would rather describe the problem than fix it yourself, open a regular issue explaining what is wrong and a maintainer will pick it up.

### Can AI write articles here?

Not wholesale. AI tools are welcome for research and for polishing drafts that you personally verify, but pasting an entire AI-generated page is grounds for deletion, and false claims produced by AI count as ordinary misinformation. The full policy is in [CONTRIBUTING.md](https://github.com/eskridd/PiPedia/blob/main/CONTRIBUTING.md).

### What happens if I break something?

Git records every edit, and each article's History button shows exactly what changed when. Any page can be rolled back, and worst case a maintainer restores an older version. Do not let fear of breaking things keep you from editing; that is what the [[Sandbox]] is for.

### Can I reuse these articles elsewhere?

Yes. The code and content are under the MIT license in the repository's LICENSE file, which means reuse is fine with attribution.

### Something missing?

If a question belongs here and is absent, add it. This wiki improves the same way everything else does: somebody notices a gap and fills it.
