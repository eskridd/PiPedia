# Open Source

**Open source** describes software whose source code is published under a license that lets anyone use, study, modify, and share it. The Open Source Initiative maintains the formal definition; licenses like MIT, Apache-2.0, GPL, and BSD qualify. Note that merely publishing code without a license does not count: without permission, the default is that nobody may reuse it.

## Where it came from

In 1983 Richard Stallman launched the GNU project on the idea that software users deserve freedom to run, study, share, and improve what runs on their machines. In 1998 the term "open source" was coined as a friendlier banner for businesses, and in 1991 [[Linux]] gave both movements the kernel-sized proof they needed. The two camps still argue about vocabulary while sharing nearly every practical goal.

## Why it won

Shared code compounds. A problem solved once (a compression algorithm, a web server, a compiler) becomes infrastructure everyone builds on:

- Linux runs most servers, clouds, and phones
- Apache and nginx deliver the majority of web pages
- Firefox and Chromium are the engines behind essentially every browser
- Python, Node.js, Rust toolchains, and SQLite quietly underpin millions of products
- Blender does professional 3D work for zero license fees

Companies discovered that giving code away recruits contributors, sets standards, and cuts costs. Today open source is less a fringe ideal than the default way serious infrastructure gets written.
